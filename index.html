About SaveIQ

SaveIQ — AI Savings Goal Tracker v2.0 · A single-file fintech application built with HTML5, CSS3 and vanilla JavaScript. Storage: browser localStorage or Google Sheets via Apps Script. AI: Groq Cloud (Llama-3.3-70B) with an offline rule-based fallback engine. Automation: daily audit trigger with Gmail deadline reminders.

SaveIQ provides educational savings guidance only and is not licensed financial advice.
